# Documentos da AGT

A base normativa da facturação electrónica em Angola. Estavam espalhados —
a especificação técnica estava na raiz do projecto com o nome
`4ed27961-97c1-43ae-a752-dc8073d8ca63.pdf`, os restantes numa pasta `tmp/`
ao lado das imagens de cada página que alguém extraiu para os ler.

Ficam aqui porque é contra eles que o módulo de facturação é escrito, e
porque quem herdar este código vai precisar deles antes de mudar uma linha
da assinatura, do SAFT-AO ou da comunicação com a AGT.

| Documento | O que é |
|---|---|
| [DS-120 — Especificação Técnica](DS-120-especificacao-tecnica-facturacao-electronica.pdf) | A especificação de serviço para entidades externas: endpoints, formato dos pedidos, assinatura. Criada em Outubro de 2025, actualizada em Novembro de 2025. É a norma que a nossa integração cumpre. |
| [Regime Jurídico da Factura](regime-juridico-da-factura.pdf) | O enquadramento legal — o que é uma factura, o que tem de conter, prazos e obrigações. |
| [Guia rápido — Portal do Parceiro](guia-rapido-portal-do-parceiro.pdf) | Como se usa o [portaldoparceiro.minfin.gov.ao](https://portaldoparceiro.minfin.gov.ao), onde se certifica o software e se gerem as séries. |
| [Guia rápido — Portal do Contribuinte](guia-rapido-portal-do-contribuinte.pdf) | Como se usa o [portaldocontribuinte.minfin.gov.ao](https://portaldocontribuinte.minfin.gov.ao), do lado da empresa. |

A lista de verificação do que já cumprimos do DS-120 está em
[`docs/ADR-2026-05-25-fe-agt-ds120-checklist.md`](../ADR-2026-05-25-fe-agt-ds120-checklist.md).
